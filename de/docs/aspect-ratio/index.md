# Seitenverhältnis


Das Seitenverhältnis wird mit dem Befehl **`--ar`** festgelegt.

```css
--ar 16:9
```

FLUX, Recraft, Nano Banana und Stable Diffusion unterstützen: **`--ar 1:1`**,**`--ar 2:3`**,**`--ar 3:2`**,**`--ar 4:5`**,
**`--ar 5:4`**,**`--ar 4:3`**, **`--ar 3:4`**, **`--ar 16:9`** und **`--ar 9:16`**

Standardmäßig gilt **`--ar 1:1`**.

Zum Beispiel:

```jsx
ein niedliches blaues Mammut in den Bergen --ar 16:9
```
