# Unterstützte Dateiendungen in Mammouth

Mammouth unterstützt eine große Auswahl an Dateitypen für Uploads, darunter Dokumente, Bilder, Code, Konfigurationsdateien und vieles mehr. Nachfolgend findest du eine nach Kategorien geordnete Liste aller unterstützten Dateiendungen.

---

## 🖼️ **Bilddateien**
Mammouth akzeptiert verschiedene Bildformate, darunter moderne und ältere Formate:

- **Rasterbilder**
  - `.png` (Portable Network Graphics)
  - `.jpg` / `.jpeg` (Joint Photographic Experts Group)
  - `.webp` (Modernes Format mit hervorragender Komprimierung)
  - `.gif` (Graphics Interchange Format, unterstützt Animationen)

- **Vektorgrafiken**
  - `.svg` (Scalable Vector Graphics)

---

## 🎵 **Audiodateien**
Mammouth unterstützt verschiedene Audioformate:

- `.wav` (Waveform Audio File Format)
- `.mp3` (MPEG Audio Layer III)
- `.aiff` (Audio Interchange File Format)
- `.acc` (Advanced Audio Coding)
- `.ogg` (Ogg Vorbis)
- `.flac` (Free Lossless Audio Codec)

---

## 🎬 **Videodateien**
Mammouth unterstützt verschiedene Videoformate:

- `.mp4` (MPEG-4 Part 14)
- `.mpeg` (Moving Picture Experts Group)
- `.mov` (QuickTime File Format)
- `.avi` (Audio Video Interleave)
- `.x-flv` (Flash Video)
- `.mpg` (MPEG Video)
- `.webm` (WebM Video)
- `.wmv` (Windows Media Video)
- `.3gpp` (3GPP Multimedia)

---

## 📄 **Dokumentdateien**
Gängige Dokumentformate für Texte, Tabellen, Präsentationen und E-Books:

- **Textverarbeitung**
  - `.pdf` (Portable Document Format)
  - `.docx` / `.doc` (Microsoft Word)
  - `.txt` (Plain Text)
  - `.rtf` (Rich Text Format)
  - `.odt` (OpenDocument Text)
  - `.epub` (E-Book-Format)

- **Tabellenkalkulation**
  - `.xlsx` / `.xls` (Microsoft Excel)
  - `.ods` (OpenDocument Spreadsheet)
  - `.csv` (Comma-Separated Values)
  - `.tsv` (Tab-Separated Values)

- **Präsentationen**
  - `.pptx` / `.ppt` (Microsoft PowerPoint)
  - `.odp` (OpenDocument Presentation)

- **Markup und Dokumentation**
  - `.md` / `.mdx` (Markdown)
  - `.rst` (reStructuredText)
  - `.adoc` (AsciiDoc)
  - `.srt` (Untertiteldateien)

### **Fazit**
Mammouth unterstützt eine umfangreiche Auswahl an Dateitypen und ist damit für unterschiedliche Anwendungsfälle geeignet – egal, ob du mit Dokumenten, Code, Bildern oder spezialisierten Formaten arbeitest. Wenn deine Dateiendung nicht aufgeführt ist, prüfe, ob es Aktualisierungen gibt, oder wandle die Datei in ein unterstütztes Format um.

Viel Spaß beim Hochladen! 🚀
