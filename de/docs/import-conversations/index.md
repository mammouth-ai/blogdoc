# Unterhaltungen aus ChatGPT oder Claude importieren

So importierst du deine Unterhaltungen in Mammouth:
- Exportiere deine Unterhaltungen aus ChatGPT oder Claude.
- Öffne deine [erweiterten Kontoeinstellungen](https://mammouth.ai/app/account/settings) und klicke auf **Unterhaltungen importieren**.
- Lade die Datei **conversations.json** hoch.

::: info Du exportierst aus Claude?
Der Export von Claude kommt jetzt als **manifest.json** mit ein paar Links darin.  
Folge dem Link zu deinen Unterhaltungen: Er lädt eine **conversations.zip** herunter.  
Entpacke sie und du findest darin die **conversations.json** zum Hochladen.  
:::

✅ Fertig!

> Einschränkungen:
> - Es werden höchstens 1.000 Nachrichten importiert, beginnend mit den neuesten.
> - Aus Sicherheitsgründen können Chats nur einmal importiert werden.
> - Es werden nur Unterhaltungen mit einer geraden Anzahl an Nachrichten importiert.
> - Unterhaltungen mit mehreren beteiligten Nutzern können nicht importiert werden.
> - Unterstützt werden nur die Exportformate von ChatGPT und Claude.
> - Die importierte Datei darf höchstens 100 MB groß sein.
