# FLUX 3 en Mammouth

FLUX 3 es el modelo de imágenes FLUX disponible en Mammouth. Sustituye a FLUX 2.

Para generar una imagen, selecciona un modelo de imagen en el campo de entrada y describe el resultado que quieres en el prompt. Compara los resultados con otros modelos para elegir el que mejor se adapte a tus necesidades.

Para aprender a especificar el formato de imagen, consulta la guía sobre la [relación de aspecto](../aspect-ratio/index.md).
