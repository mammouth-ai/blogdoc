# Cómo redactar prompts eficaces

## ¿Qué es un prompt?

Para aprovechar todo el potencial de Mammouth, aprende a comunicarte con claridad con los modelos de IA.

Los prompts son el lenguaje del diálogo entre tú y la IA. Establecen el marco del intercambio y determinan la calidad de las respuestas. Una formulación clara genera resultados pertinentes y útiles.

**Lo esencial**: trabajar con IA no requiere conocimientos técnicos. Solo tienes que aprender a comunicarte con ella como lo harías con un colaborador.

## Principios clave

1. 🎯 **Sé preciso**: formula tu petición con claridad y evita las instrucciones vagas.
2. 📝 **Aporta contexto**: especifica el tema, el público y el formato deseado.
3. 🔤 **Incluye ejemplos**: sirven de referencia para la IA.
4. 👨‍🎤 **Asigna un rol**: una persona concreta orienta el tono de la respuesta.
5. 🏗️ **Divide la tarea**: guía a la IA paso a paso en las tareas complejas.
6. 🧪 **Prueba**: si tú entiendes las instrucciones, la IA también podrá hacerlo.
7. 🔄 **Itera**: ajusta las instrucciones hasta obtener el resultado deseado.

## Estructura recomendada

<span style="color: #d9534f;">**Rol**</span>: asigna una persona a la IA.

<span style="color: #f0ad4e;">**Objetivo**</span>: ¿cuál es su misión? Detalla los pasos para procesos complejos.

<span style="color: #5cb85c;">**Público**</span>: especifica a quién debe dirigirse la IA.

<span style="color: #5bc0de;">**Restricciones/estilo**</span>: reglas que delimitan el comportamiento (idioma, formato, frecuencia).

<span style="color: #9b59b6;">**Formato de salida**</span>: especifica el resultado esperado (texto, tabla, código).
