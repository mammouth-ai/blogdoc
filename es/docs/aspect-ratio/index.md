# Relación de aspecto

La relación de aspecto se define con el comando **`--ar`**.

```css
--ar 16:9
```

FLUX, Recraft, Nano Banana y Stable Diffusion admiten estas relaciones: **`--ar 1:1`**, **`--ar 2:3`**, **`--ar 3:2`**, **`--ar 4:5`**,
**`--ar 5:4`**, **`--ar 4:3`**, **`--ar 3:4`**, **`--ar 16:9`** y **`--ar 9:16`**.

La relación predeterminada es **`--ar 1:1`**.

Ejemplo:

```jsx
un mamut azul adorable en las montañas --ar 16:9
```
