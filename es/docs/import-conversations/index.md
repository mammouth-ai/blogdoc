# Importar conversaciones de ChatGPT o Claude

Para importar tus conversaciones a Mammouth, sigue estos pasos:
- Exporta tus conversaciones desde ChatGPT o Claude.
- Ve a los [ajustes avanzados de tu cuenta](https://mammouth.ai/app/account/settings) y haz clic en **Importar conversaciones**.
- Sube el archivo **conversations.json**.

::: info ¿Exportas desde Claude?
La exportación de Claude llega como un archivo **manifest.json** que contiene algunos enlaces.  
Sigue el que lleva a tus conversaciones; descargará un archivo **conversations.zip**.  
Descomprímelo y encontrarás el archivo **conversations.json** que puedes subir a Mammouth AI.  
:::

¡Listo!

> Limitaciones:
> - Se importarán como máximo 1000 mensajes (los más recientes).
> - Por motivos de seguridad, las conversaciones solo se pueden importar una vez.
> - Solo se importarán las conversaciones con un número par de mensajes.
> - No se pueden importar conversaciones en las que participen varios usuarios.
> - Por el momento, solo se admiten los formatos de exportación de ChatGPT y Claude.
> - El archivo importado no puede superar los 100 MB.
