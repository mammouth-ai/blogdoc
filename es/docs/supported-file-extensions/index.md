# Extensiones de archivo compatibles con Mammouth

Mammouth admite una amplia variedad de tipos de archivo para subir, incluidos documentos, imágenes, código, archivos de configuración y mucho más. A continuación encontrarás una lista organizada por categorías de las extensiones compatibles.

---

## 🖼️ **Archivos de imagen**
Mammouth acepta distintos formatos de imagen, tanto modernos como antiguos:

- **Imágenes rasterizadas**
  - `.png` (Portable Network Graphics)
  - `.jpg` / `.jpeg` (Joint Photographic Experts Group)
  - `.webp` (Formato moderno con excelente compresión)
  - `.gif` (Graphics Interchange Format, admite animaciones)

- **Gráficos vectoriales**
  - `.svg` (Scalable Vector Graphics)

---

## 🎵 **Archivos de audio**
Mammouth admite distintos formatos de audio:

- `.wav` (Waveform Audio File Format)
- `.mp3` (MPEG Audio Layer III)
- `.aiff` (Audio Interchange File Format)
- `.acc` (Advanced Audio Coding)
- `.ogg` (Ogg Vorbis)
- `.flac` (Free Lossless Audio Codec)

---

## 🎬 **Archivos de vídeo**
Mammouth admite distintos formatos de vídeo:

- `.mp4` (MPEG-4 Part 14)
- `.mpeg` (Moving Picture Experts Group)
- `.mov` (QuickTime File Format)
- `.avi` (Audio Video Interleave)
- `.x-flv` (Flash Video)
- `.mpg` (MPEG Video)
- `.webm` (WebM Video)
- `.wmv` (Windows Media Video)
- `.3gpp` (3GPP Multimedia)

---

## 📄 **Archivos de documentos**
Formatos habituales para textos, hojas de cálculo, presentaciones y libros electrónicos:

- **Procesamiento de texto**
  - `.pdf` (Portable Document Format)
  - `.docx` / `.doc` / `.docm` (Microsoft Word)
  - `.txt` (Texto sin formato)
  - `.rtf` (Rich Text Format)
  - `.odt` (OpenDocument Text)
  - `.epub` (Formato de libro electrónico)

- **Hojas de cálculo**
  - `.xlsx` / `.xls` / `.xlsm` (Microsoft Excel)
  - `.ods` (OpenDocument Spreadsheet)
  - `.csv` (Valores separados por comas)
  - `.tsv` (Valores separados por tabulaciones)

- **Presentaciones**
  - `.pptx` / `.ppt` (Microsoft PowerPoint)
  - `.odp` (OpenDocument Presentation)

- **Marcado y documentación**
  - `.md` / `.mdx` (Markdown)
  - `.rst` (reStructuredText)
  - `.adoc` (AsciiDoc)
  - `.srt` (Archivos de subtítulos)

---

### **Conclusión**
Mammouth admite una amplia variedad de tipos de archivo, por lo que resulta versátil para distintos usos, tanto si trabajas con documentos, código, imágenes o formatos especializados. Si tu extensión no aparece en la lista, comprueba si hay actualizaciones o conviértela a un formato compatible.

¡Que disfrutes subiendo archivos! 🚀
