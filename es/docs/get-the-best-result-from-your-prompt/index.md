# Obtén el mejor resultado para tu prompt

## Nadie sabe qué IA responderá mejor a tu prompt hasta que las compares

Las clasificaciones actuales del rendimiento de los LLM, como las de [lmsys.org](http://lmsys.org) o [livebench.ai](http://livebench.ai), estiman la probabilidad de que un modelo supere a otro en categorías específicas. En particular, el LLM mejor clasificado solo tiene una probabilidad ligeramente superior al 50 % de superar al segundo.

Incluso con algoritmos sofisticados que tienen en cuenta las clasificaciones específicas por categoría (por ejemplo, razonamiento, programación, redacción o idiomas), las diferencias de rendimiento no son significativas.

Por eso, el mejor enfoque es volver a enviar el prompt a otros modelos y comparar:

- Vuelve a enviar el prompt a un segundo modelo.
- Disponer de varias propuestas de IA te permite elegir el mejor resultado.

## Datos empíricos de Mammouth

### **Datos de nuevas consultas en Mammouth AI**

| **Número de modelos de texto consultados por prompt** | **% del total de prompts** |

| >= 4                                                  | 7 %                        |

| >= 2                                                  | 34 %                       |
| = 1                                                   | 66 %                       |

| **Número de modelos de imagen consultados por prompt** | **% del total de prompts** |
| ---------------------------------------------------- | -------------------------- |
| >= 3                                                 | 19 %                       |
| >= 2                                                 | 41 %                       |
| = 1                                                  | 59 %                       |

### En el 66 % de las consultas de texto diarias, los usuarios recurren a un solo modelo

- El 66 % de las consultas de los usuarios no requiere volver a enviar el prompt (según los datos de [Mammouth.ai](http://Mammouth.ai)).

### En el 34 % de las consultas de texto diarias, los usuarios recurren a más de un modelo

- Por tanto, el 34 % del total de consultas se beneficia de volver a enviar el prompt. Son consultas de gran valor, más creativas y complejas.
  - El 24 % del total de prompts se vuelve a enviar a exactamente 1 modelo.
  - El 12 % del total de prompts se vuelve a enviar a 2 modelos o más.
  - El 7 % del total de prompts se vuelve a enviar a más de 3 modelos.

## Volver a enviar el prompt es aún más habitual con herramientas de generación de imágenes

- De hecho, el 41 % de las consultas de imágenes se vuelve a enviar a al menos otro modelo.
- El 19 % de esas consultas se vuelve a enviar a más de dos modelos.

## A medida que los modelos de IA mejoran, definir el mejor resultado se vuelve más subjetivo y menos objetivo

Hay dos motivos para preferir el resultado de un modelo al de otro:

- **Motivo objetivo**: el usuario preferirá el modelo que siga las instrucciones del prompt y proporcione la respuesta correcta.
- **Motivo subjetivo**: cuando dos IA ofrecen respuestas objetivamente correctas, el usuario puede preferir una de ellas por motivos subjetivos.

→ A medida que mejora el rendimiento de las IA, la diferencia entre modelos pasa gradualmente de lo objetivo a lo subjetivo. Por eso, comparar respuestas resulta cada vez más útil. De ahí surge este [Índice de popularidad de los LLM](../introducing-llm-popularity-index/).
