# Tutoriel Mammouths Personnalisés

Lien rapide pour les abonnés : [Créer un mammouth](https://mammouth.ai/app/assistants/)

## **Qu'est-ce qu'un mammouth personnalisé ?**

Dans Mammouth, vous pouvez créer votre équipe d’assistants spécialisés pour vous aider dans vos tâches quotidiennes.

C’est comme un mammouth sur mesure, dont les instructions contextuelles et les fichiers attachés s’appliquent à toutes vos conversations.

> 💡*Bon à savoir : les ingénieurs appellent cette instruction "prompt système".*

![Custom Mammouth](custom_mammouth_FR.png)

## **Quelle bonne pratique pour instruire un mammouth ?**

:::info ✅ À FAIRE : Donner 3 types d'instructions :
- Un rôle
- (optionnel) Une connaissance spécifique
- (optionnel) Une méthodologie donnée
:::

:::info 🚫 À NE PAS FAIRE : Donner une tâche (ex. "corrige mon email"). 
La tâche est pour le prompt.
:::

## **🦣 Astuces pour les mammouths**

### Choisir un modèle par défaut par mammouth

Chaque mammouth peut avoir son **propre modèle par défaut** et son propre ordre d'affichage des modèles. Par exemple, configurez modèle par défaut pour vos projets de développement et un autre modèle pour votre mammouth créatif.

### Mammouths favoris

Marquez vos mammouths les plus utilisés comme favoris ⭐ pour qu'ils apparaissent toujours en haut de la liste.

### Personnaliser l'apparence de votre mammouth

Personnalisez votre mammouth avec un large choix de couleurs et d'accessoires pour le rendre vraiment unique ! 🎨

## 🔍 **Rechercher et gérer vos conversations**

### Rechercher dans l'historique de conversation

Appuyez sur **CTRL+K** ou cliquez sur l'icône 🔍 de recherche dans la barre latérale pour rechercher instantanément par mot-clé dans tous vos messages passés. Cela vous permet de retrouver rapidement cette discussion que vous avez eue il y a des semaines.

> 💡*Bon à savoir : vous pouvez aussi rechercher des conversations par modèle ou par nom de mammouth.*

### Opérations multiples sur les conversations

Besoin de faire du ménage ? Vous pouvez sélectionner plusieurs conversations à la fois pour les supprimer ou les déplacer en lot.
