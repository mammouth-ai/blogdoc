# Importare conversazioni da ChatGPT o Claude

Per importare le tue conversazioni in Mammouth, segui questi passaggi:
- Esporta le tue conversazioni da ChatGPT (o Claude).
- Vai alle [impostazioni avanzate del tuo account](https://mammouth.ai/app/account/settings) e fai clic su **Importa conversazioni**.
- Carica il file **conversations.json**.

::: info Esporti da Claude?
L'esportazione di Claude è disponibile sotto forma di **manifest.json**, che contiene alcuni collegamenti.  
Segui quello che rimanda alle tue conversazioni: scaricherà un file **conversations.zip**.  
Estrai il contenuto e troverai **conversations.json**, da utilizzare su Mammouth AI.  
:::

✅ Fatto!

> Limitazioni:
> - Verranno caricati al massimo 1000 messaggi, i più recenti.
> - Per motivi di sicurezza, le conversazioni possono essere importate una sola volta.
> - Verranno importate solo le conversazioni con un numero pari di messaggi.
> - Non è possibile importare conversazioni con più utenti partecipanti.
> - Al momento sono supportati solo i formati di esportazione di ChatGPT e Claude.
> - Il file importato non deve superare i 100 MB.
