# FLUX 3 in Mammouth

FLUX 3 è il modello di generazione delle immagini FLUX disponibile in Mammouth. Sostituisce FLUX 2.

Per generare un'immagine, seleziona un modello di immagini nell'area di input e descrivi nel prompt il risultato che desideri. Confronta i risultati con quelli di altri modelli per scegliere quello più adatto alle tue esigenze.

Per specificare il formato dell'immagine, consulta la guida al [formato delle immagini](../aspect-ratio/index.md).
