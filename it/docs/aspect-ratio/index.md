# Formato delle immagini

Il formato dell'immagine si definisce con il comando **`--ar`**

```css
--ar 16:9
```

FLUX, Recraft, Nano Banana e Stable Diffusion accettano i seguenti rapporti: **`--ar 1:1`**, **`--ar 2:3`**, **`--ar 3:2`**, **`--ar 4:5`**,
**`--ar 5:4`**, **`--ar 4:3`**, **`--ar 3:4`**, **`--ar 16:9`** e **`--ar 9:16`**


Il valore predefinito è **`--ar 1:1`**

Esempio:

```jsx
un mammut blu carino in montagna --ar 16:9
```
