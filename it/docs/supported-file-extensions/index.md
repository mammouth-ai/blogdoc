# Estensioni di file supportate da Mammouth

Mammouth supporta un'ampia gamma di tipi di file da caricare, tra cui documenti, immagini, codice, configurazioni e molto altro. Di seguito trovi un elenco organizzato per categorie delle estensioni supportate.

---

## 🖼️ **File immagine**
Mammouth accetta diversi formati di immagine, sia moderni sia meno recenti:

- **Immagini raster**
  - `.png` (Portable Network Graphics)
  - `.jpg` / `.jpeg` (Joint Photographic Experts Group)
  - `.webp` (Formato moderno con compressione eccellente)
  - `.gif` (Graphics Interchange Format, supporta le animazioni)

- **Grafica vettoriale**
  - `.svg` (Scalable Vector Graphics)

---

## 🎵 **File audio**
Mammouth supporta diversi formati audio:

- `.wav` (Waveform Audio File Format)
- `.mp3` (MPEG Audio Layer III)
- `.aiff` (Audio Interchange File Format)
- `.acc` (Advanced Audio Coding)
- `.ogg` (Ogg Vorbis)
- `.flac` (Free Lossless Audio Codec)

---

## 🎬 **File video**
Mammouth supporta diversi formati video:

- `.mp4` (MPEG-4 Part 14)
- `.mpeg` (Moving Picture Experts Group)
- `.mov` (QuickTime File Format)
- `.avi` (Audio Video Interleave)
- `.x-flv` (Flash Video)
- `.mpg` (MPEG Video)
- `.webm` (WebM Video)
- `.wmv` (Windows Media Video)
- `.3gpp` (3GPP Multimedia)

---

## 📄 **File di documenti**
Formati comuni per testi, fogli di calcolo, presentazioni ed e-book:

- **Elaborazione testi**
  - `.pdf` (Portable Document Format)
  - `.docx` / `.doc` / `.docm` (Microsoft Word)
  - `.txt` (Testo semplice)
  - `.rtf` (Rich Text Format)
  - `.odt` (OpenDocument Text)
  - `.epub` (Formato e-book)

- **Fogli di calcolo**
  - `.xlsx` / `.xls` / `.xlsm` (Microsoft Excel)
  - `.ods` (OpenDocument Spreadsheet)
  - `.csv` (Valori separati da virgole)
  - `.tsv` (Valori separati da tabulazioni)

- **Presentazioni**
  - `.pptx` / `.ppt` (Microsoft PowerPoint)
  - `.odp` (OpenDocument Presentation)

- **Markup e documentazione**
  - `.md` / `.mdx` (Markdown)
  - `.rst` (reStructuredText)
  - `.adoc` (AsciiDoc)
  - `.srt` (File di sottotitoli)

---

### **Conclusione**
Mammouth supporta un'ampia varietà di tipi di file, rendendolo versatile per diversi casi d'uso, che si tratti di documenti, codice, immagini o formati specializzati. Se l'estensione del tuo file non è nell'elenco, controlla gli aggiornamenti o valuta la conversione in un formato supportato.
